The product is the general configuration, publication and audit workspace. Domain examples teach its use. Historical evidence records the conditions of each execution; native composition and managed workflow publication have different contracts.

The current managed Designer supports up to eight ordered decision blocks. Older
guides/screenshots showing a single insertion slot describe the earlier UI.
New LIVE provider validation for the visual extension remains pending explicit
authorization; the new receipts cover local/synthetic execution and real browser
interaction, not new model invocations.
